# Реальные автомобильные разборы

Файлы кейсов должны называться `case-*.md`. Раздел намеренно не содержит демонстрационных историй.

Публикуется только кейс, для которого можно честно описать:

- автомобиль или достаточный контекст;
- исходную проблему;
- что именно проверяли;
- принятое решение и его логику;
- фактический результат;
- фотографии — только при наличии права на публикацию.

Не добавлять вымышленные цифры, отзывы, стоимость работ, диагностические выводы или клиентские истории ради заполнения страницы.
