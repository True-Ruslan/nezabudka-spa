# NEZABUDKA v0.1.1 Production Hardening Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship v0.1.1 with reproducible installs, publication-ready case detail routes, a custom 404, stronger mobile navigation, static-output integrity checks, and a real post-deploy smoke test.

**Architecture:** Keep Astro fully static and dependency-light. Extend the existing content collection into static case detail pages, add build verification using Node built-ins, and keep deployment gated by CI plus a post-release HTTP check. No unverified personal content is introduced.

**Tech Stack:** Astro 6.3.x, TypeScript 5.9.x, Node.js 24, Playwright 1.55.x, GitHub Actions / GitHub Pages, plain CSS.

**Spec:** `docs/superpowers/specs/2026-09-06-v0.1.1-production-hardening-design.md`

## Global Constraints

- Keep Astro 6 and Node.js 24.
- Keep the site fully static; no backend, CMS, database, React, Tailwind, or UI framework.
- Do not publish unverified contact data, cases, metrics, testimonials, certificates, or AI portraits.
- Preserve the existing Precision Editorial visual direction.
- Internal URLs must remain safe for both `/nezabudka-spa/` and a future custom-domain root.
- `case-template.md` must remain unpublished.
- Every behavior change follows red → green verification before merge.

**Files:**

- Modify: `.github/workflows/ci.yml`

**Interfaces:**
- Consumes: `dist/`, `BASE_PATH`/default project Pages convention.
- Produces: CLI exit 0 on valid static graph; non-zero with actionable messages on broken local references.

- [ ] **Step 1: Write the verifier with deterministic helpers**

The file must implement these pure responsibilities using Node built-ins:

```js
const ignoredSchemes = /^(?:https?:|mailto:|tel:|data:|javascript:)/i;

function isLocalReference(value) {
  return value && !value.startsWith('#') && !ignoredSchemes.test(value) && !value.startsWith('//');
}

function stripQueryAndHash(value) {
  return value.split('#', 1)[0].split('?', 1)[0];
}
```

Then:
- recursively collect all files under `dist`;
- require `dist/index.html` and `dist/404.html`;
- extract `href` and `src` attributes from each HTML file;
- resolve root-relative URLs after stripping `/nezabudka-spa/` in default CI mode;
- resolve directory URLs to `<path>/index.html`;
- fail when an expected local target does not exist;
- assert homepage HTML contains `https://true-ruslan.github.io/nezabudka-spa/` in default mode;
- assert no `dist/cases/case-template/index.html` exists.

Print all failures before setting `process.exitCode = 1`.
